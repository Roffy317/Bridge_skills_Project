# Bridge Skills Programme Analysis (Excel)

## Project Overview
This project analyses the 2025 Bridge Skills Programme dataset to evaluate programme participation, training activities, and programme value across different locations and skill categories.

## Data Cleaning
- Cleaned and standardised the dataset.
- Removed 9 duplicate records.
- Corrected inconsistent text entries.
- Handled missing values.
- Prepared the data for analysis.

## Key Metrics & Insights
- Total Programme Value: ₦5,722,000
- Total Records: 660
- Total Sessions: 2,995
- Average Value per Participant: ₦8,670
- Analysed performance across four locations and four skill categories.

## Tools & Skills
- Microsoft Excel
- Data Cleaning
- Excel Formulas
- PivotTables
- Data Analysis
- Data Visualisation

## Objective
To transform raw programme data into meaningful insights that support programme evaluation, monitoring, and decision-making.
